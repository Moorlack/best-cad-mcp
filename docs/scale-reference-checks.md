# Контроль длины и масштаба

У analyze_architectural_drawing появился необязательный reference_lengths:

```json
[
  {"handle": "A1", "length": 304.8, "units": "mm", "source": "Контрольный размер, предоставленный инженером"}
]
```

Передавайте настоящий handle из свежего скана и внешний контрольный размер.
Пример A1 не означает существующую сущность. Поддерживаются только отдельные
LINE в снимке, 1–20 уникальных handles; единицы mm/cm/m/in/ft и источник обязательны.
Источник — предоставленное пользователем основание, его достоверность автоматически
не проверяется. Использовать длину из самого скана как независимый контроль нельзя.

Из start/end вычисляется пространственная длина (включая Z), затем значение
пересчитывается в метры по заявленным единицам DWG и сравнивается с контролем.
Кэшированное поле length, подписи размеров, текст атрибутов и масштаб печати
не используются. Вставленные блоки, полилинии, размеры DIMENSION и другие
геометрические типы этим шагом не поддерживаются. Unitless, неизвестные единицы
и единицы вне mm/cm/m/in/ft дают not_verified, а не догадку.

В report.scale_reference_check:

- checks: исходный контроль, измеренная длина в единицах DWG и метрах,
  контроль в метрах, reference_to_measured_ratio и статус;
- agrees: совпадение в пределах max(1e-9 м, 1e-6 × максимальная сравниваемая длина);
- mismatch: длины различаются; ratio — отношение контрольной длины к измеренной,
  а не разрешение масштабировать весь DWG;
- not_verified: нет однозначного handle, неподдерживаемая сущность, неполные
  координаты, нулевая длина, неизвестные единицы или выход чисел за диапазон;
- all_references_agree относится исключительно к перечисленным линиям;
  geometry_scale_verified остаётся false.

Сверка не подтверждает масштаб всех объектов или обоснованность контрольных
данных. Карточка проекта, её история, INSUNITS и геометрия не меняются.
При entity_limit, обрезающем нужный handle, результат будет not_verified;
повторите анализ с достаточным лимитом. Необязательный project_id можно передать
одновременно: сверка единиц карточки остаётся отдельной проверкой.

## Живой smoke-test после Repair

Новый CMD не требуется: обновиться прежним Repair / Extend и перезапустить
AutoCAD/клиент. Живой тест установленной версии этого шага пока не выполнен.

В тестовом DWG с INSUNITS=1 (дюймы) создать на отдельном слое линию длиной 12
единиц и записать полученный handle. После scan_all_entities вызвать анализ:

1. reference_lengths с length=1, units=ft, source=synthetic smoke test → agrees,
   измерение 12 единиц / 0.3048 м, ratio=1.
2. Тот же handle с length=2, units=ft → mismatch, ratio=2.
3. Несуществующий handle → not_verified.
4. Вызов без reference_lengths работает как прежде без scale_reference_check.

Если INSUNITS другой, контрольный размер адаптировать к фактическим единицам,
не менять единицы DWG для удобства теста. При неизвестных единицах ожидается
not_verified. Зафиксировать handle/слой/результаты в backlog, DWG автоматически
не сохранять. Геометрия тестовая; совпадение проверяет алгоритм и транспорт,
не является независимой проверкой масштаба инженерного проекта.
