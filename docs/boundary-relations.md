# Взаимное положение контуров

`analyze_architectural_drawing` возвращает `boundary_relations`. Проверяются
только контуры со статусом valid_simple_polygon в boundary_checks: прямолинейные,
замкнутые, горизонтальные и с известными координатами WCS.

В `items`:

- `contains`: outer_handle геометрически содержит inner_handle без контакта
  рёбер. hole_status=unverified: вложенность не доказывает отверстие.
- `intersection_or_touch`: рёбра контуров пересекаются, касаются или совпадают
  в пределах допуска. Указываются оба исходных handles. Требуется проверка.

Раздельные контуры не создают запись. Проверенные пары на разных высотах
учитываются в different_plane_pairs. Вложенность многоуровневая: если A содержит
B и C, а B содержит C, будут перечислены все три отношения. Автоматический
выбор внешнего контура/отверстия/островка пока не выполняется.

Обязательные ограничения:

- holes_confirmed=false и net_area_calculated=false. Исходная геометрическая
  площадь каждого контура не уменьшается, суммарная площадь не вычисляется.
- excluded_contour_handles перечисляет контуры с invalid/not_verified.
  Дуги, отверстия в блоках/Xrefs и другие неподдерживаемые формы не проверяются.
- entity_coverage_truncated отмечает неполный набор сущностей отчёта.
- checked_pairs/total_pairs/unverified_pairs показывают полноту проверки.
  Первые 20 непроверенных пар имеют причины в unverified_pair_samples.
- Бюджет 500000 попарных проверок рёбер, резервируемый по числу рёбер пары;
  базовый лимит остаётся 100 контуров по 256 вершин.
- Геометрия нормализуется по общему габариту пары, допуск 1e-9. Разница высот
  сравнивается с допуском относительно меньшего контура. При отношении размеров
  менее 1e-6 пересекающиеся габариты дают not-verified для пары вместо догадки.
  Проверка консервативна: близкие рёбра могут считаться касающимися.

## Проверка после Repair

Обновление использует прежний CMD и зависимости. После перезапуска клиента и
AutoCAD нужно выполнить свежий scan. Живой тест этого обновления ещё не выполнен.

На отдельном тестовом слое создать четыре замкнутые полилинии и сохранить
полученные handles в ходе проверки (не использовать handles прошлого теста):

1. A: прямоугольник (20000,0)—(20010,10), площадь 100.
2. B: прямоугольник (20002,2)—(20004,4), площадь 4.
3. C: прямоугольник (20009,6)—(20012,8), площадь 6.
4. D: прямоугольник (20020,0)—(20022,2), площадь 4.

После scan_all_entities с clear_annotations=false/clear_understanding=false
и analyze_architectural_drawing ожидаются A contains B, контакт/пересечение A–C,
никаких отношений с D. Площадь A остаётся 100, не 96; holes_confirmed=false,
structural_design_ready=false. Проверить отсутствие пропусков/усечения для
контрольных пар. Иные объекты DWG могут давать дополнительные отношения.

Для регрессии прошлого обновления можно добавить отдельно самопересекающуюся
полилинию: она должна быть invalid и попасть в excluded_contour_handles.
Не сохранять DWG автоматически. По завершении записать созданные handles,
слой, результаты и состояние документа в backlog.
