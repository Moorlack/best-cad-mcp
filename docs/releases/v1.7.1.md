# v1.7.1 - Reproducible CAD agent experiment baselines

This release adds a source-checkout workflow for comparing CAD agents on the
same drawing, guidance and budgets. It does not claim a GPT-6 performance gain
or a newly completed live AutoCAD evaluation.

- Freeze drawings, source, skill references, prompts, task criteria and optional
  independent judge assets into a content-hashed baseline.
- Record complete-component grounding, reviewed unintended edits, repair rounds,
  tool calls, wall time, token usage and human interventions.
- Reject changed evidence, stale edit snapshots and incompatible experiment
  records. Pending, blocked and unresolved results remain unknown.
- Include two pilot tasks against the existing flange-coupling DXF and an
  independent-review protocol. The pilot still needs live target annotation.

The ledger runs from a source checkout with
`python scripts/agent_benchmark.py`; it is not an MCP tool or model-provider
integration. See [the experiment guide](../agent-benchmark.md).

This release also includes previously merged changes since v1.7.0: guarded
workflow prompt improvements, AutoCAD raster-grounding alignment fixes, the
recorded live flange-coupling demo, rollback smoke coverage, documented known
limitations, and Ruff linting in release CI. The historical demo uses
deterministic CADPlans and is separate from the new model comparison pilot.

Validation for the new ledger covers frozen input/evidence integrity,
incomplete results, zero-label grounding, budgets, intervention, unintended
edits, mismatched drawings, and incompatible runs. Local validation passed:
421 tests and 473 subtests, Ruff, wheel/sdist builds, and Twine checks. No live
AutoCAD drawing was modified during this change; actual model
comparisons require a running AutoCAD session and independent review.
