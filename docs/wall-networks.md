# Группы связанных линий стен

Архитектурный отчёт теперь содержит `wall_networks` без дополнительных
параметров или инструментов. Это компоненты графа контактов именованных
wall/LINE: соединения концов, Т-стыки, пересечения, наложения и дубли.
Связность транзитивна: A касается B, B касается C — все три входят в группу.
Одиночные линии тоже возвращаются, с kind=isolated_line.

Для каждой группы возвращаются ID, исходные handles и candidate IDs, слои,
трёхмерный bbox_wcs и все проверенные отношения с их количеством.
ID зависит от идентичности чертежа и состава исходных кандидатов, не от порядка
сканирования. Изменение состава меняет ID; это не постоянный ID физической стены.
Изменение координат без изменения состава не меняет ID.

При явном wall_gap_tolerance список gap_links связывает найденные зазоры
с ID групп. Зазоры не соединяют группы. within_same_network означает, что
концы уже связаны другим путём внутри группы. Точки не перемещаются.

Группа может содержать много стен, случайные пересечения и дубли. Ни число
физических стен, ни их толщина, ни несущая роль, ни помещения из неё не следуют.
physical_walls_assembled=false и structural_design_ready=false остаются.
Параллельные грани одной стены без контактов пока остаются отдельными группами.

Область: только допустимые именованные горизонтальные LINE, максимум 100,
с теми же численными допусками, что wall_line_diagnostics. Разные плоскости
не объединяются. Исключения, непроверенные пары и усечение явно передаются;
coverage_complete относится только к этому ограниченному набору и становится
false при любом из этих ограничений (в том числе у каждой группы).
Непроверенная связь может соединять две показанные группы: при неполном
покрытии их число не является окончательным.

## Проверки и установка

93 теста выбранного набора и линтер прошли. Проверены транзитивность,
разные высоты, независимость от порядка, область ID по DWG, контакты разных
слоёв, дубли/наложения/Т-стыки, зазоры без склейки, исключения, лимиты и
непроверенные пары. Новый CMD и зависимости не нужны: прежний Repair / Extend.
Живой тест установленного обновления ожидается после перезапуска пользователем.

Сценарий живого теста на отдельном слое MCP-TEST-WALL-NETWORK:
A=(24000,0)→(24010,0), B=(24010,0)→(24020,0),
C=(24015,-5)→(24015,5), D=(24020.25,0)→(24030,0).
После свежего scan ожидаются группа A/B/C и отдельная D. При допуске 0.5
зазор B–D имеет расстояние 0.25 и связывает две группы, не объединяя их.
Проверять свежие handles: другие объекты в DWG могут давать другие группы.
Повторный scan должен подтвердить неизменную геометрию после анализа.
