# Возможные разрывы между концами линий стен

Необязательный параметр analyze_architectural_drawing `wall_gap_tolerance`
включает поиск близких концов раздельных горизонтальных LINE — кандидатов wall.
Значение должно быть конечным положительным числом **в единицах координат DWG**.
Например, 0.5 при дюймовых координатах означает половину дюйма, а не полмиллиметра.
По умолчанию поиск выключен: допустимый размер зазора не выбирается за инженера.

В wall_line_diagnostics.gap_search:

- requested и tolerance_drawing_units — запрос и использованный порог;
- drawing_units — единицы снимка, включая unknown, если они не установлены;
- disjoint_pairs_checked — число проверенных раздельных пар в одной плоскости;
- candidates — ближайшая пара концов для каждой подходящей пары линий,
  handles, start/end, исходные координаты и distance_drawing_units.

Порог включительный: расстояние <= wall_gap_tolerance. Пересекающиеся, уже
касающиеся или накладывающиеся линии не дублируются как зазоры. Линии на разных
высотах не соединяются. Результат — кандидат для проверки, не дефект: разрыв
может быть проёмом или намеренным разделением. Изменений геометрии нет.

Ограничения прежние: только именованные кандидаты wall/LINE, до 100 линий;
исключения, непроверенные пары и усечение отмечаются в отчёте. gaps_checked=true
означает завершённый поиск в этом ограниченном наборе при запрошенном пороге,
а не проверку всех стен DWG. При исключениях/усечении значение false, хотя часть
кандидатов может быть найдена. Значение unknown у единиц не подменяется догадкой:
порог всё равно выражен в числовых единицах координат, физическая интерпретация
требует проверки масштаба. Проёмы, толщина стен, конец–середина сегмента,
содержимое блоков и полилинии этим поиском не проверяются.

## Проверка установленного MCP после Repair

Прежний CMD → Repair / Extend → перезапуск AutoCAD и клиента. Новые зависимости
не нужны. Живой тест установленного MCP выполнен 2026-09-24: PASS (см. ниже).

Создать на отдельном слое MCP-TEST-WALL-GAPS две линии:
A: (22000,0) → (22010,0), B: (22010.25,0) → (22020,0).
Записать реальные handles и выполнить свежий scan.

1. Без wall_gap_tolerance → requested=false, кандидатов зазоров нет.
2. С wall_gap_tolerance=0.5 → пара A–B, расстояние 0.25, концы end(A)/start(B).
3. С wall_gap_tolerance=0.2 → пары A–B среди кандидатов нет.
4. Проверить, что геометрия после анализа не менялась и готовность к расчёту false.

Старые тестовые объекты могут дать дополнительные пары: проверять именно новые
handles, не требовать единственного результата во всём DWG. Геометрию теста
оставить для проверки, файл автоматически не сохранять, результат записать в backlog.
