# Проёмы и участки стен

`analyze_architectural_drawing(wall_thickness_range=[min, max], wall_opening_max_width=W)`
добавляет в `wall_segment_candidates.openings` связь кандидатов door/window/opening
(по именам слоя/блока) с участками стен и разрывами граней.

## Разрывы граней (`gaps`)

Только при явном `wall_opening_max_width` (единицы координат DWG; без
`wall_thickness_range` — ошибка). Разрыв — промежуток между концами двух осей
участков на одной линии (боковое смещение ≤ 10% толщины), длиной 0 < gap ≤ W.
Для разрыва: ID, участки, длина, толщина, начало/конец на оси. Общее ядро —
`find_axis_gaps` в `axis_junctions.py`; вне архитектуры его можно вызывать из Python.

## Статус кандидата

Сравнивается bbox кандидата с полосами «ось ± полтолщины» разрывов и участков
(общий `region_overlap.py`: площадь пересечения, для плоского bbox — доля длины):

| status | Значение |
| --- | --- |
| `in_wall_gap` | bbox пересекает разрыв граней — геометрия поддерживает реальный проём |
| `on_wall_segment` | пересекает только нарисованные грани — символ поверх непрерывной стены |
| `not_on_wall_segment` | ни с одним участком не пересекается; issue `opening_not_on_wall_segment` |

Разрывы без кандидата перечислены в `gaps_without_opening_candidate` (issue
`wall_gap_without_opening_candidate`): неподписанный проём или разрыв чертежа.
`opening_verified=false` всегда. bbox включает дуги открывания и подписи, поэтому
размер, тип и сторона открывания проёма не определяются; влияние на конструкцию
не оценивается. Без поиска разрывов дверь в проёме обычно получает
`not_on_wall_segment`: bbox лишь касается концов граней.

## Сценарий живой проверки (TEST2.dwg, INSUNITS=in)

- A-WALL-TEST: W1/W2 (11000..11100, y 2000/2008), W3/W4 (11136..11300), W5/W6 (11340..11400);
- A-DOOR: прямоугольник (11100,1998)–(11136,2010) в разрыве 36 и (12000,3000)–(12036,3036) вдали;
- A-WINDOW: LINE (11200,2004)–(11240,2004) поверх непрерывной стены.

`wall_thickness_range=[4,12], wall_opening_max_width=48` → 2 разрыва (36 и 40);
дверь в разрыве `in_wall_gap`, окно `on_wall_segment`, дальняя дверь
`not_on_wall_segment`, разрыв 40 — без кандидата.
