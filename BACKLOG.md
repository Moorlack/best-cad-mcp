### Исходные инженерные направления

| Направление | Что получает инженер | Статус |
| --- | --- | --- |
| Разбор архитектурного DWG | Стены, проёмы, оси, контуры перекрытий со ссылками на исходные объекты и отмеченными неоднозначностями | Частично: базовый инвентарь кандидатов |
| Карточка проекта | Адрес, этажность, назначение, материалы, единицы, исходные данные и применимые редакции норм | Базовая версия реализована; smoke-test из Claude прошёл |
| Проверяемые расчётные инструменты | Нагрузки, грузовые площади, реакции и проверки элементов с воспроизводимыми результатами | Не реализовано |
| Источники нормативных требований | Для каждого принятого значения — документ, редакция, пункт и условия применимости | Не реализовано |
| Skills и плагин для Claude | Последовательный рабочий процесс и правила обработки недостающих данных | Специализированный комплект не реализован; есть документация и тестовый промпт |
| Выпуск результатов | Схема в DWG, ведомость элементов и отчёт, связанные общими идентификаторами | Инженерный выпуск не реализован |
